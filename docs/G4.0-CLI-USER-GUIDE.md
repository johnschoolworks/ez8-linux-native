# G4.0 Unified CLI User Guide

## Scope

Experimental Linux-native eZ8 tooling targeting Z8F0822.
The unified CLI provides offline assembler, object, linker,
firmware, and mock debugger commands.

It does not expose physical Flash, reset, run, or halt operations.

## Installation

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
source .venv/bin/activate
ez8 --help
```

The tested development installation used locally available
setuptools and wheel with an editable package installation.

## Commands

```sh
ez8 --help
ez8 asm --help
ez8 object --help
ez8 link --help
ez8 firmware --help
ez8 debug-mock --help
```

## Reproduce the G3.9 three-LED firmware

Run from the repository root after installing `ez8`.

```sh
mkdir -p build/g40-guide-example

python3 -B examples/z8f0822/build_sequencer.py \
  --output build/g40-guide-example/baseline

ez8 object examples/z8f0822/startup.asm   --section STARTUP   -o build/g40-guide-example/startup.ezo

ez8 object build/g40-guide-example/baseline/sequencer.asm   --section CODE   -o build/g40-guide-example/sequencer.ezo

ez8 firmware   build/g40-guide-example/startup.ezo   build/g40-guide-example/sequencer.ezo   --vector-template examples/z8f0822/reset-only.hex   --vector-manifest examples/z8f0822/manifests/reset-only.json   -o build/g40-guide-example/sequencer.hex

sha256sum build/g40-guide-example/sequencer.hex
```

Expected SHA-256:

`90f1867a54c22b6e02cfa780af9bb8218e27b8ec5981820a7f00046ff0bdcb03`

The sequencer assembly file is a generated G3.9 build artifact.
This example regenerates its G3.9 baseline from committed public sources.

Do not interpret successful firmware generation as permission
to flash a target. Hardware operations require separate validation.
