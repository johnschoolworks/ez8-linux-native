# 0.4.0 Public Release Readiness

Release target: **public GitHub release v0.4.0**, requested by the user.
Repository: https://github.com/johntsaiainow/ez8-linux-native

The source distribution, wheel, Debian package, and VS Code extension use
version 0.4.0. `tools/build-release.sh` runs the full Python regression and
extension handler tests, builds the assets, checks archive contents, tests an
isolated wheel install and extracted Debian launchers, and writes checksums
and `dist/release-validation.json`.

The 0.1.0 Debian launcher issue is fixed by the private application launcher
calling `ez8native.cli:main`. Packaging is architecture-independent, declares
Python, removes bytecode caches, and normalizes permissions and root ownership.
The extension now supports a configurable executable, help, active-file
assembly, missing-executable handling, and trusted workspaces.

Public scope and remaining limitations are described in
[release notes](RELEASE-0.4.0.md). Vendor manuals and device backup binaries are
excluded from new distribution artifacts; existing local copies are preserved.
The historical [RC manifest](G4.0-RC-MANIFEST.md) describes an earlier baseline
and is not the current public-release authorization record.

Local validation is recorded separately from publication. A successful build
does not mean that a tag or release has been uploaded. The release must refer
to the commit containing these fixes, with only the reviewed download assets
attached. No PyPI or Marketplace publication is requested.
