# eZ8 Linux Native v0.4.0-rc1

Status: Release Candidate Approved
Formal release: NOT AUTHORIZED
Python package version: 0.4.0rc1

## Overview

Experimental native Linux toolchain for Zilog eZ8 / Z8F0822.

## Features

- Native assembler with verified eZ8 instruction subset.
- Experimental EZO objects and relocations.
- Native linker and firmware builder.
- Intel HEX generation and validation.
- Unified CLI: asm, object, link, firmware, debug-mock.

## Qualification

Historical engineering regression: 397 tests, 24 subtests passed.
Public snapshot regression: 325 tests, 24 subtests passed.

The previously qualified 0.4.0 Wheel reproduced the
Golden Firmware byte-for-byte.

Qualification of the new 0.4.0rc1 Wheel is PENDING.

## Limitations

- Full eZ8 ISA coverage is not implemented.
- No native C compiler is provided.
- No physical Flash, reset, run or halt CLI operations.
- Firmware generation does not authorize hardware programming.
